# Tic-Tac-Toe Game (Fun Game)

A simple, browser-based Tic-Tac-Toe game built with plain JavaScript, HTML, and CSS.

This repository contains a small, well-documented implementation of the classic Tic-Tac-Toe game that you can play locally in your browser or use as a starting point for learning DOM manipulation and game logic in JavaScript.

## Features
- 3x3 Tic-Tac-Toe board
- Two-player gameplay (local)
- Win / Draw detection
- Simple, responsive UI
- Clean, readable JavaScript code for game logic

## Languages
- JavaScript — ~38%
- CSS — ~36%
- HTML — ~26%

## Demo
Open `index.html` in your browser to play the game locally.
